# 老板画像

最后更新：2026-05-07

## 已确认

- 老板使用中文沟通。
- 老板希望先把现有文档整理好，再说明项目目标。
- 老板偏好我主动推进，不要停在“要不要我做”的确认里。
- 老板当前更重视 March 的愿景和产品范式，不希望旧架构里的 Rust/Tauri 等选型绑架方向。
- 老板对 Electron 体积敏感，倾向先用最快、轻量的方式验证产品。
- 老板明确不要任务看板，更认可先定大框架，Agent 执行过程中逐步补细节。
- 老板对工程整洁度和架构演进要求高；不能接受大量调试垃圾残留，也不能接受把早期调试 HTML/简单 JS 脚本包装成可持续工程。

## 暂定判断

- 技术参与度：有技术判断力。整理文档时给清晰结构和待确认点，等老板抛目标后再展开实现方案。
- 关注点：把散落设计资料收敛成可讨论、可追踪、可执行的大框架；细节允许在 Agent 执行过程中生长，但工程基线、清理纪律和架构升级不能被“快速验证”长期拖欠。
- 工作方式：能做的先做；不确定的地方标注推测，集中留给老板确认。
