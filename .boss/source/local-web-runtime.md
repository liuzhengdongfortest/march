# 本地 Web 运行时

最后更新：2026-05-07

## 决策：第一阶段使用本地 Web App

**为了谁**：服务于快速验证 [愿景中心](../requirements/VISION.md)。

**怎么设计**：Node/TypeScript 后端提供 SQLite、git、Pi Adapter、Provider、SSE/WS 和 REST API；前端在浏览器中运行 IM 风格界面。

**为什么这样**：老板明确不想为了壳先背上 Electron 体积，也不要求继续 Rust/Tauri。浏览器前端能最快验证群聊模型。

## 决策：全局 WS + 当前群 SSE

**为了谁**：服务于多群后台活跃。

**怎么设计**：全局 WebSocket 推群列表摘要、未读、最后消息预览。用户打开某群时，单独建立该群 SSE，接收聊天消息、Agent streaming、状态和框架更新。

**为什么这样**：当前群需要高频细节，非当前群只需要低带宽摘要。

## 决策：桌面壳后置

**为了谁**：服务于实现节奏。

**怎么设计**：先保证 `localhost` 本地应用完整可用。后续根据需要评估轻量桌面壳、系统托盘、文件关联和后台常驻。

**为什么这样**：桌面壳解决分发和系统集成，不解决群聊协作是否成立。
